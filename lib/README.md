
# MaBiblio

Application Flutter de gestion et de consultation d'un
catalogue de livres, réalisée dans le cadre du TP
« Listes et grilles ».

## Fonctionnalités

- Catalogue de livres avec ListView, Card et ListTile.
- Galerie responsive avec GridView.builder.
- Affichage en grille ou en liste.
- Détail d'un livre avec auteur, année et genre.
- Gestion des livres lus.
- Gestion des favoris.
- Filtrage des nouveautés.
- Chargement initial des données depuis un fichier JSON.
- Sauvegarde locale des livres lus et des favoris.
- Réinitialisation de la bibliothèque.
- Navigation entre Catalogue, Galerie et Ma liste.

## Technologies

- Flutter
- Dart
- JSON
- path_provider
- Material Design

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/kenza04122/DEVMOB-LibrairiePro.git
```

Entrer dans le projet :

```bash
cd DEVMOB-LibrairiePro
```

Installer les dépendances :

```bash
flutter pub get
```

Lancer l'application :

```bash
flutter run
```
